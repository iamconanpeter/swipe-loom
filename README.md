# Swipe Loom

Android puzzle MVP where players swipe between adjacent pegs to weave required thread patterns within a move budget.

## Local setup

```bash
export JAVA_HOME=/home/openclaw/.openclaw/workspace/.local/jdk-17
export ANDROID_SDK_ROOT=/home/openclaw/.openclaw/workspace/.local/android-sdk
export PATH=$JAVA_HOME/bin:$PATH
./gradlew test assembleDebug
```
